# @egonitida/core

Simulation core of EgoNitida, deterministic on every host.

> EgoNitida is unstable. Until it stabilizes, its core APIs may change in breaking ways, without backward compatibility.

## Usage

```sh
npm install @egonitida/core
```

## Requirements

| Requirement  | Supported                           |
| ------------ | ----------------------------------- |
| Chrome, Edge | 136 or later, 144 or later on Linux |
| Firefox      | 141 or later                        |
| Safari       | 26 or later                         |
| Node.js      | `>=24.11.1`                         |
| workerd      | Any                                 |
