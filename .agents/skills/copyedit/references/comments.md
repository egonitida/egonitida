# Commenting

## General

| ID      | Rule                                                                                                                                                                                | Fits                                                                                                                                                                                                          | Misses                                                                                                                                                                |
| ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| C-GEN-1 | Every declaration other than a parameter carries a comment, every local declaration and every field included.                                                                       | `/** A point in a plane. */` above `type Point`; `/** The distance from the center. */` above `radius`; `// The position in the list.` above `const index = 0` inside a function; a parameter with no comment | `type Point` with no comment above it; `radius` with no comment above it; `const index = 0` with no comment above it; `@param radius - The distance from the center.` |
| C-GEN-2 | Every comment other than the comment on a module states in one sentence only what the thing it stands on is or does beyond what the name and the type of the thing say.             | `/** The distance from the center. */` for `radius: number`; `/** A point in a plane. */` for `Point`                                                                                                         | `/** A number. */` for `radius: number`; `/** The radius. */` for `radius`; `/** A point: not a line, as it has no length. */` for `Point`                            |
| C-GEN-3 | Every comment on a declared type opens with "A" or "An", and every comment on a declared field or value opens with "The".                                                           | `/** A point in a plane. */` for `Point`; `/** The distance from the center. */` for `radius`; `// Imports resolved by Rolldown instead.` beside a configured option                                          | `/** Point in a plane. */` for `Point`; `/** A distance from the center. */` for `radius`                                                                             |
| C-GEN-4 | Every comment on a function says what the function does, opening with a verb in the third person other than the name of the function, even where the function makes a single thing. | `/** Creates a point from two coordinates. */` for `make`                                                                                                                                                     | `/** Makes a point. */` for `make`; `/** A function that makes a point. */` for `make`; `/** Create a point from two coordinates. */` for `make`                      |
| C-GEN-5 | Every comment on a schema reads "A schema of" followed by the comment on the type the schema describes.                                                                             | `/** A schema of a point in a plane. */` beside `/** A point in a plane. */`                                                                                                                                  | `/** Validates a point. */` beside `/** A point in a plane. */`                                                                                                       |

## Lean

| ID       | Rule                                                                                                                                                                                                                                                                                             | Fits                                                                                                                                                                                                                                              | Misses                                                                                                                                                    |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| C-LEAN-1 | Every module carries a comment between `/-!` and `-/` that opens with the title under `#` and a summary, followed by the notation under `## Notation`, the notes on the implementation under `## Implementation notes`, and the references under `## References`, each where the module has any. | `/-! # Machine` and a summary, then `## Notation` with δ* named as the iterated transition function, then `## References` with the works cited `-/`; `/-! # Machine` and a summary alone for a module with no notation, notes, or references `-/` | a module with no comment; `/-! # Machine … ## Main definitions … -/`; `/-! Machine … -/` with no `#` before the title; δ* used with no notation naming it |
| C-LEAN-2 | Every comment on a theorem states the theorem in one sentence that ends with the formula of the theorem, where the theorem has one.                                                                                                                                                              | `/-- Adding two numbers $a$ and $b$ in either order gives one sum, $a + b = b + a$. -/`; `/-- Every machine has exactly one homomorphism into the final machine. -/`                                                                              | `/-- Proves that addition commutes. -/`; `/-- Adding two numbers in either order gives one sum. -/` for a theorem with a formula                          |
