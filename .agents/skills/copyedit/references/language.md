# Language

## Scope

| ID      | Rule                                                                                                                                        | Fits                                                                 | Misses |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- | ------ |
| L-SCO-1 | Every rule holds for the words a text chooses, never for a name, a version, or a quotation that an outside library, product, or work gives. | `Array.reduce` from Effect; TLS 1.3; a quotation that reads "colour" | —      |
| L-SCO-2 | Where two rules disagree, the more specific rule holds.                                                                                     | L-SYN-1 over L-SYN-4: the state of a machine                         | —      |

## Lexicon

| ID      | Rule                                                                                                                                        | Fits                                                                                                                                                                  | Misses                                                                                                                                                                   |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| L-LEX-1 | Every name says what it stands for, never how it is made.                                                                                   | `generator`, `identifier`, `clock`                                                                                                                                    | `mulberry32`, `nanoid`, `performanceNow`                                                                                                                                 |
| L-LEX-2 | Every term comes from the field that defines the thing it names, in the meaning of that field.                                              | `fold` for combining a list into one value in order; velocity for the rate at which a position changes; `map` for making a list by applying a function to every value | `reduce` for combining a list into one value in order; speed for the rate at which a position changes; `forEach` for making a list by applying a function to every value |
| L-LEX-3 | Every word outside the terms of a field is taken in the meaning a dictionary gives it, never in a convention or in how it strikes a reader. | replace a value in a state, find a key in a map, clear a cache, start a server                                                                                        | update a value in a state, fetch a key from a map, blow away a cache, spin up a server                                                                                   |
| L-LEX-4 | Every name is made of words a dictionary lists, except an initialism a field uses in place of the words and a symbol in a formula.          | `position`, `configuration`, `index`, `Input`, and `url` for names; x in f(x) = y for a symbol in a formula                                                           | `pos`, `cfg`, `idx`, and `I` for names; `x` for the name of a variable in code                                                                                           |
| L-LEX-5 | Every thing keeps across every text the one name L-LEX-2 gives, and takes added words only to tell its roles apart.                         | `state` in every module; `currentState` and `successorState` for two roles of a state; machine in every sentence, where the field also says automaton                 | `state` in one module and `status` in another; `state` and `snapshot` for one state; machine in one sentence and automaton in the next                                   |
| L-LEX-6 | Every boolean is named by the quality it states, in the positive, and every function that asks for one starts with `is` or `has`.           | `enabled` and `visible` for values; `isEmpty(list)` and `has(set, value)` for functions that ask                                                                      | `disabled` and `isEnabled` for values; `isNotEmpty(list)` and `contains(set, value)` for functions that ask                                                              |
| L-LEX-7 | Every term that ranks people or marks a group of people gives way to a term for what the thing does.                                        | allowlist and denylist; primary and replica; `main`; confidence check; placeholder                                                                                    | whitelist and blacklist; master and slave; `master`; sanity check; dummy                                                                                                 |

## Syntax

| ID      | Rule                                                                                                                     | Fits                                                                                                                              | Misses                                                                                            |
| ------- | ------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| L-SYN-1 | Every possessive outside a name a field gives is said with the preposition its relation takes, never with an apostrophe. | the state of a machine; the model by Codd; the request from the user; the work of a day; Newton's method for a name a field gives | a machine's state; Codd's model; the user's request; a day's work                                 |
| L-SYN-2 | Every item of a list takes the grammatical form of the other items.                                                      | The function sorts a list, filters it, and maps the result.                                                                       | The function sorts a list, filters it, and the result is mapped.                                  |
| L-SYN-3 | Every sentence runs from start to end without a clause or a phrase set off by commas in the middle.                      | The cache holds every key in a map. The parser reads a file as a stream.                                                          | The cache, which is kept as a map, holds every key. The parser, a streaming reader, reads a file. |
| L-SYN-4 | Every sentence takes the shortest construction that keeps the sentence exact and the other rules allow.                  | to sort; can read; uses a map; the state of a machine                                                                             | in order to sort; is able to read; makes use of a map                                             |

## Semantics

| ID      | Rule                                                                                                                   | Fits                                                                                                    | Misses                                                                                                        |
| ------- | ---------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| L-SEM-1 | Every description says what a thing is or does, never what it is worth.                                                | runs in constant time; holds one value; reads every file once; Run the tests.                           | is fast; is simple; is powerful; Simply run the tests.                                                        |
| L-SEM-2 | Every statement covers exactly the cases it is true of.                                                                | The function sorts any array.                                                                           | The function sorts an array of numbers, narrowed; The function sorts any collection, widened.                 |
| L-SEM-3 | Every statement carries one negation at most, counting a negating word, a negating prefix, and "without."              | The cache is often full. The step runs only with a cache.                                               | The cache is not infrequently full. The step never runs without a cache.                                      |
| L-SEM-4 | Every symbol is named before the first use of the symbol, in the text or in the notation the text cites.               | Iterating over a sequence σ from a state x reaches δ*(x, σ).                                            | δ*(x, σ) with x and σ named nowhere                                                                           |
| L-SEM-5 | Every statement of what a thing is or does is in the present tense.                                                    | The function returns a copy. The cache holds every key. Mealy defined the machine in 1955.              | The function will return a copy. The cache would hold every key.                                              |
| L-SEM-6 | Every definition says just enough to tell the thing defined apart from the other things of its kind, and nothing more. | A center is a point at the middle of a circle. `/** A point at the middle of a circle. */` for `Center` | A center is a point in a plane. A center is a point at the middle of a circle, held as two numbers in memory. |

## Reference

| ID      | Rule                                                                                                        | Fits                                                                                                      | Misses                                                                                    |
| ------- | ----------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| L-REF-1 | Every pronoun for a thing points to the last thing that could be meant, and any other thing is named again. | The parser reads the file and closes it. The parser reads the file, and then the parser stops.            | The parser reads the file, and then it stops. When it starts, the parser reads the file.  |
| L-REF-2 | Every person or group of people a text speaks of is named, never stood for by a personal pronoun.           | The compiler checks the types. Knuth defined the algorithm. The paper cites the work that inspired Knuth. | We check the types. He defined the algorithm. The paper cites the work that inspired him. |
